# Lampa Cinema

Плагин-агрегатор онлайн-источников для Lampa. Версия 0.2.0.

## Текущее состояние

- Плагин регистрирует пункт **Lampa Cinema** в контекстном меню карточки.
- В каталоге присутствуют 23 планируемых источника.
- Реализован публичный поисковый адаптер AniLibria (API v3).
- Получение прямого видеопотока пока не реализовано; найденные результаты не запускаются в плеере.
- Остальные источники отображаются как «в разработке» и не выдают фиктивные результаты.

## Подключение

`https://amirsz01.github.io/lampa-cinema/online_balancers.js`

## Безопасность и ограничения

Используются только публичные API без встроенных приватных токенов, чужих cookies и секретных CORS-прокси. Авторизация, DRM и платный доступ не обходятся. Для каждого следующего адаптера перед реализацией проверяются публичная документация, CORS, условия использования и поддерживаемые форматы потоков.

## Источники

AniLibria API: https://github.com/anilibria/docs/blob/master/api_v3.md

## План реализации

1. Проверка доступности API каждого источника и его условий использования.
2. Реализация поиска и нормализации результатов.
3. Получение доступных дорожек/эпизодов через документированные интерфейсы.
4. Поддержка прямых HLS/DASH/MP4 потоков, если это разрешено API и поддерживается Lampa.Player.
5. Интеграционные проверки на реальном устройстве.
